## 使用方法（二选一）

### 方法一：复制源码

1. 备份你的仓库，或新建分支。
2. 把本压缩包“源码文件”目录中的全部内容复制到仓库根目录，保留原有目录结构并覆盖同名文件。
3. 在仓库根目录打开终端，执行：

```powershell
git switch -c add-four-custom-cards
git add src tools content localization DESIGN.md ECONOMY.md
git commit -m "Add Last Will, Fighting Chance, Restart Future and Let Go"
git push -u origin add-four-custom-cards
```

然后在 GitHub 仓库中打开该分支，点击 Compare & pull request。
如果该分支名已经存在，请换一个名称。覆盖方式可能覆盖你对同名文件的本地修改，有本地修改时推荐用方法二。

### 方法二：应用补丁（推荐已有本地修改时使用）

将 add-four-cards.patch 放到仓库根目录，在该目录执行：

```powershell
git switch -c add-four-custom-cards
git apply --check add-four-cards.patch
git apply add-four-cards.patch
git add src tools content localization DESIGN.md ECONOMY.md
git commit -m "Add Last Will, Fighting Chance, Restart Future and Let Go"
git push -u origin add-four-custom-cards
```

如果补丁检查报错，说明文件与你当前版本有冲突，请先处理冲突，不要直接覆盖本地修改。
复制源码和应用补丁只需选一种，不要重复执行。

## 新卡规则

- 遗志：稀有攻击，X费。消耗X费对应的能量、全部信号，以及全部待偿还的资源透支，对所有敌人造成三者消耗量乘积的伤害；进入玩家自己的下一个回合时强制死亡。升级增加保留。任何一项为0，乘积为0，仍施加死亡效果。
- 一线生机：稀有技能，0费。仅当能量和信号同时为0时可手动打出。获得1能量、1信号，抽2张牌，消耗。升级增加保留。
- 重启未来：稀有能力，1费，升级0费。从能力生效后的出牌开始计数，每12次出牌结算强制结束当前回合，使用原生额外回合接口跳过敌方行动，开始自己的新回合。计数跨回合累计，重放也计数，同名能力不叠加。
- 割舍：罕见技能，0费。从当前存在的能量／抽牌／信号透支类型中等概率选一种，减少1点，然后自选1张手牌消耗。没有透支或其他手牌时仍可打出。升级增加保留。

透支计数只包含待偿还的能量、抽牌和信号透支，每一点为一层。百分比伤害／格挡惩罚以及正在生效的当回合惩罚不参与计算或移除。

## 卡面与构建

四张新卡保留指定中文名称，暂复用仓库已有图片占位；没有加入新的图片文件。清单中使用 custom、placeholder 字段明确标记。需要更换时修改 content/artwork-map.json 中对应条目的 sourceFile、sha256、width、height 等信息。

这是源码更新包，不是可直接放入游戏 mods 目录的安装包。dist 中原有发布包没有更新。需在配置好环境的仓库中重新构建：

```powershell
git lfs pull
.\build.ps1 -Godot 'C:\tools\Godot_v4.5.1-stable_win64_console.exe' -NoInstall
```

Godot路径请替换为实际路径。脚本按原仓库约定推导游戏目录，推荐将源码放在“游戏目录/.modding/PhigrosJiu”。使用原仓库的构建和打包流程制作安装包。

## 主要实现位置

- tools/card_design.py：四张牌定义、升级与文本。
- src/CustomCardEffects.cs：遗志资源消耗与群攻、割舍偿还与选牌消耗。
- src/Powers.cs：延迟死亡、12张计数与原生额外回合。
- src/GeopeliaCard.cs：X费、出牌限制及新效果接入。
- content/artwork-map.json：占位卡面绑定。
- 其余文件：生成的牌池、本地化、能力资源清单及89张牌的构建／编辑器适配。
